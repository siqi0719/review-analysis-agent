# 问题关系拓扑

## 运行
在项目根目录 `D:\Agent` 下执行：

```bash
python skills/issue_topology/run.py --days 90
```

| 参数 | 说明 | 默认 |
|---|---|---|
| `--start` / `--end` | 日期范围 YYYY-MM-DD | 截至数据最新日期 |
| `--days` | 未给 `--start` 时取最近 N 天 | 90 |
| `--min-count` | 画连线所需的最少共现评论数 | 10 |
| `--no-analyze` | 不调用大模型补分析范围内未处理的评论 | 默认会补 |

在 Python 中调用：`from skills.issue_topology.run import run; result = run(days=90)`。

## 方法
- 统计口径：至少带一个负面问题的评论（不含「其他」标签）
- **lift = P(A∩B) / (P(A)·P(B))**：lift > 1 表示两个问题一起出现的次数比随机情况多，2 表示多一倍
- 只保留共现评论数 ≥ min-count 且 lift > 1 的连线，过滤偶然结果
- 问题聚类：在以 lift 为权重的关联网络上做 Louvain 社区发现
- 满意度落差：带该负面问题的评论平均满意度，减去不带该问题的评论平均满意度

## 输出
`reports/skills/issue_topology_<开始>_<结束>.html`，包含：
1. 力导向网络图：节点大小 = 评论数，颜色 = 平均满意度（红低蓝高），连线粗细 = lift；可拖拽、缩放
2. 各问题对满意度的影响条形图
3. 问题关联热力图
4. 关联最强的问题对及评论摘要示例

## 注意
时间范围太短时（少于约 30 条负面评论）样本不足，脚本会报错提示扩大范围。
30 天的数据连线会比较少，建议至少用 60–90 天。
