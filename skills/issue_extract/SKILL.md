# 问题提取与分类

## 运行
在项目根目录 `D:\Agent` 下执行：

```bash
python skills/issue_extract/run.py --days 30
```

| 参数 | 说明 | 默认 |
|---|---|---|
| `--start` / `--end` | 日期范围 YYYY-MM-DD | 截至数据最新日期 |
| `--days` | 未给 `--start` 时取最近 N 天 | 30 |
| `--top` | 典型原话展示前几个负面问题 | 6 |
| `--no-analyze` | 不调用大模型补分析范围内未处理的评论 | 默认会补 |

在 Python 中调用：`from skills.issue_extract.run import run; result = run(days=30)`，
返回 `{"insights": [...], "data": {...}, "html": 报告路径}`。

## 输出
`reports/skills/issue_extract_<开始>_<结束>.html`，包含：
1. 各方面正负面评论数对比条形图
2. 负面问题构成旭日图（内圈问题大类，外圈具体问题）
3. 与上一周期相比的负面率变化（每百条评论）
4. 每个主要负面问题的典型原话

## 解读要点
- 计数口径是「提到该方面的评论条数」，同一条评论多次提到同一方面只算一次
- **负面率** = 每百条已分析评论中提到该负面问题的条数，用于跨时间段比较
- **负面占比** = 负面 ÷（正面 + 负面），反映该方面的口碑好坏
- 「其他」是没能归入 16 个标签的内容，部分来自混入的商场类门店
