# 满意度变化

## 运行
在项目根目录 `D:\Agent` 下执行：

```bash
python skills/satisfaction_trend/run.py
```

| 参数 | 说明 | 默认 |
|---|---|---|
| `--start` / `--end` | 日期范围 YYYY-MM-DD | 全部数据 |
| `--days` | 未给 `--start` 时取最近 N 天 | 全部数据 |
| `--min-n` | 判断异常时当天最少评论数 | 15 |
| `--no-analyze` | 不调用大模型补分析范围内未处理的评论 | 默认会补 |

在 Python 中调用：`from skills.satisfaction_trend.run import run; result = run()`。

## 方法
- **满意度**：用户总评分（1–5）为主，缺失时用大模型判断的分数补上
- **7 日移动平均**：按评论数加权，避免评论很少的日子让曲线大幅波动
- **异常下跌**：当天评论数 ≥ min-n，且 z = (当天均值 − 前 28 天均值) / (前 28 天单条标准差 / √当天条数) ≤ −2，同时至少比基线低 0.3 分
- **下跌原因**：异常当天各负面问题的出现率（每百条评论）与前 28 天相比增加最多的问题
- **门店变化**：最近 30 天对比之前 30 天，两段都至少有 15 条评论的门店

## 输出
`reports/skills/satisfaction_trend_<开始>_<结束>.html`

## 注意
- 分项评分（口味/环境/服务）只有约 72% 的评论有，分项趋势仅供参考
- 评论少于 30 条的周不参与「最高/最低周」排名
